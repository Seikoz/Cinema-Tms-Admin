# Cinema TMS Admin 1.1.0 Beta 1

- 관리자 DB를 프로젝트의 `data\licenses.db`에 새로 만들었습니다.
- 새 Ed25519 발급기관 키를 생성하고 개인키는 최초 설정 전까지 현재 Windows 계정의 DPAPI로 보호합니다.
- 최초 관리자 계정 설정이 끝나면 개인키는 관리자 암호 기반 AES-GCM 형식으로 DB에 저장되어 다른 PC에서도 사용할 수 있습니다.
- 클라우드 공유 시 한 번에 한 PC에서만 실행하고 종료 후 동기화 완료를 확인하는 운용 규칙을 문서화했습니다.
- 새 공개 검증키를 Cinema TMS 클라이언트와 동기화했습니다.

이 변경은 관리자 DB의 공유 운용과 새 발급기관 초기화를 추가한 기능 변경이므로 MINOR 버전을 올렸습니다.
