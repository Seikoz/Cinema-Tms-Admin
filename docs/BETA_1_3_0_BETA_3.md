# Cinema TMS Admin 1.3.0 Beta 3

- 고객명·영화관명과 로그인·계정 관리 모달의 편집 가능한 입력창을 `ttk.Entry`에서 클래식 `tk.Entry` 기반 입력창으로 변경했습니다.
- Windows 한글 IME가 조합 중인 문자열을 애플리케이션 이벤트가 읽거나 다시 쓰지 않도록 기본 입력 처리만 사용합니다.
- 읽기 전용 필드와 숫자 전용 Spinbox, 관리자 DB 및 라이선스 발급 규격은 변경하지 않습니다.

Windows 한글 입력 호환성의 추가 수정이므로 `1.3.0b2`에서 `1.3.0b3`로 패치 버전을 올렸습니다.
