# Cinema TMS Admin 1.6.0 Beta 3

## 로그인 연동 자동 업데이트

- 공용 GitHub 읽기 전용 토큰을 `licenses.db`의 `secure_settings`에 AES-GCM 암호문으로 저장합니다.
- 암호화 키는 로그인으로 해제된 Ed25519 발급키에서 업데이트 전용 HKDF 컨텍스트로 파생하므로 DB와 로그인 계정을 함께 이전하면 다른 개발 PC에서도 재입력 없이 사용할 수 있습니다.
- 기존 `data/github-update-token.dpapi`는 관리자 로그인 직후 DB로 한 번만 이전하고 검증한 뒤 삭제합니다.
- `온라인 업데이트`와 라이선스 발급은 로그인된 계정으로 DB 자격 증명을 자동 사용하며 GitHub 로그인 및 토큰 입력창을 표시하지 않습니다.
- 토큰 변경은 관리자만 가능하고, 발급 담당자는 암호문을 복호화해 라이선스 발급에만 사용할 수 있습니다.

기존 기능의 인증 저장 및 UI 흐름을 보완한 패치이므로 `1.6.0b3`으로 판올림했습니다.
