# Cinema TMS Admin 1.3.0 Beta 5

## 네이티브 입력창 강제 종료 수정

- `1.3.0b4`에서 한글 IME를 위해 추가한 네이티브 `EDIT` 컨트롤의 Win32 창 프로시저 가로채기를 제거했습니다.
- ctypes 콜백이 Windows 보안 검사에 걸려 종료 코드 `0xC0000409`로 프로그램이 강제 종료되던 문제를 수정했습니다.
- 입력값 동기화는 Win32 콜백 스택이 아닌 Tk 이벤트 루프에서 30ms 간격으로 안전하게 처리합니다.
- 네이티브 Windows IME 인라인 조합 방식과 기존 DB·발급 형식은 그대로 유지됩니다.

긴급 안정성 수정이므로 `PATCH`로 판단해 `1.3.0b5`로 올렸습니다.
