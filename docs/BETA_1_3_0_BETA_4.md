# Cinema TMS Admin 1.3.0 Beta 4

## Windows 네이티브 한글 IME 입력

- 고객명, 영화관명, 날짜 및 로그인·계정 관리 모달의 편집 입력창을 Windows 네이티브 `EDIT` 컨트롤로 변경했습니다.
- 한글 조합 중인 글자가 Tk 보조 창에 따로 나타나는 현상을 제거하고, 조합 글자·커서·후보 UI가 입력창 안에서 처리되도록 했습니다.
- 입력값은 기존 `StringVar` 및 라이선스 발급 로직과 양방향 동기화되므로 DB와 발급 파일 형식은 변경되지 않습니다.
- 다른 운영체제에서는 기존 Tk 입력창으로 자동 대체됩니다.

기존 기능의 Windows 입력 호환성 수정이므로 `PATCH`로 판단해 `1.3.0b4`로 올렸습니다.
