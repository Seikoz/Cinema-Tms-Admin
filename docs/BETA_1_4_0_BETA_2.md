# Cinema TMS Admin 1.4.0 Beta 2

## 기존 라이선스 만료일 범위 오류 수정

- 하드웨어 키로 불러온 기존 라이선스의 만료일이 `9999-12-31`일 때 365일을 더하면서 `date value out of range`가 발생하던 문제를 수정했습니다.
- 날짜 최댓값에 가까운 라이선스는 `9999-12-31`을 그대로 유지합니다.
- 일반 라이선스는 기존 만료일과 현재 날짜 중 늦은 날짜를 기준으로 365일 연장합니다.

기존 기능의 날짜 계산 오류 수정이므로 `PATCH`로 판단해 `1.4.0b2`로 올렸습니다.
