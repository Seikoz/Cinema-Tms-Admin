# Cinema TMS Admin 1.1.0 Beta 3

- 관리자 프로젝트에 독립 `.python` 오프라인 런타임을 배치했습니다.
- VBS, CMD, 패키지 빌더에서 형제 `Cinema_Tms` 프로젝트 런타임 참조를 제거했습니다.
- TMS 클라이언트 소스나 런타임이 없어도 관리자 프로그램 실행과 패키지 생성이 가능합니다.
- 관리자 DB, 로그인 계정, 암호화 개인키 및 발급 이력은 기존 `data\licenses.db`를 그대로 사용합니다.

프로그램 경계와 런타임 의존성을 바로잡은 패치이므로 `1.1.0b2`에서 `1.1.0b3`으로 올렸습니다.
