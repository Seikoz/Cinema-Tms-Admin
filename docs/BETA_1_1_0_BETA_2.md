# Cinema TMS Admin 1.1.0 Beta 2

- 분리된 관리자 소스 프로젝트에 `.python` 또는 `.venv`가 없을 때 형제 `Cinema_Tms\.python` 런타임을 자동으로 사용합니다.
- 관리자 패키지 빌더도 형제 오프라인 런타임을 재사용할 수 있도록 수정했습니다.
- 처리되지 않은 Python 시작 오류와 Tk 콜백 오류를 `data\admin-error.log`에 기록하고 사용자에게 로그 위치를 표시합니다.
- 기존 DB, 로그인 계정, 발급키와 라이선스 이력은 변경하지 않습니다.

관리자 실행 오류 수정이므로 `1.1.0b1`에서 `1.1.0b2`로 패치 버전을 올렸습니다.
