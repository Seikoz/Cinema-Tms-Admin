# Cinema TMS Admin 1.7.0 Beta 2

## 온라인 업데이트 진행률 팝업

- 상단 계정 상태에 남던 `비공개 GitHub Release에서 새 버전 확인 중` 문구를 제거했습니다.
- `온라인 업데이트` 제목의 모달 팝업에서 자격 증명 확인, 업데이트 정보 확인, 다운로드, 무결성 검증 및 설치 준비 단계를 표시합니다.
- 업데이트 파일의 전체 크기와 내려받은 바이트를 기준으로 실제 다운로드 진행률과 MB 단위를 표시합니다.
- 최신 버전, 설치 확인 취소, 오류 시 팝업과 업데이트 버튼 상태를 정상적으로 복구합니다.
- 버전 확인과 설치 준비는 불확정 진행 표시를 사용하며 다운로드만 실제 0~100%를 표시합니다. 파일 교체는 관리자 종료 후 기존 업데이트 도구가 수행합니다.
- 설치 프로그램 실행 실패 시 기존 로그인 상태를 유지합니다.

기존 업데이트 화면 표시를 보완한 패치이므로 `1.7.0b2`로 판올림했습니다.
