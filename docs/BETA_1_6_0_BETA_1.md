# Cinema TMS Admin 1.6.0 Beta 1

## 변경 사항

- 공용 읽기 전용 GitHub 토큰을 Windows DPAPI로 암호화 저장합니다.
- 최신 `.tmshw`의 장비별 공개키로 토큰을 암호화해 스키마 4 라이선스에 서명합니다.
- 발급 DB에는 공개키만 기록하며 평문 토큰은 기록하지 않습니다.
- 기존 하드웨어 요청 스키마 1은 조회 호환하지만, 자동 토큰을 포함한 신규 발급에는 스키마 2 파일이 필요합니다.

## 보안 경계

설치 패키지와 Git 저장소에는 공용 토큰을 포함하지 않습니다. 토큰 폐기나 교체 시 관리자에서 새 토큰을 설정하고 라이선스를 재발급합니다.
