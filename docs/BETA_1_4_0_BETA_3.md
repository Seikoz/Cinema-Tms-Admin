# Cinema TMS Admin 1.4.0 Beta 3

## 발급 이력·입력 글꼴·UTC+9 표시 수정

- 발급 이력에 하드웨어 ID 열을 추가하고 라이선스 ID와 하드웨어 ID가 잘리지 않도록 최소 너비를 확대했습니다.
- 작은 화면에서도 전체 ID를 확인할 수 있도록 가로·세로 스크롤을 추가했습니다.
- Windows 네이티브 입력창이 Tk 기본 글꼴의 실제 크기·굵기·기울기를 사용하도록 변경해 한글만 크게 보이던 문제를 수정했습니다.
- DB와 감사 이력은 기존처럼 UTC로 저장하되 라이선스 관리자 화면과 오류 로그에서는 항상 UTC+9로 표시합니다.

화면 표시 호환성 수정이므로 `PATCH`로 판단해 `1.4.0b3`로 올렸습니다.
