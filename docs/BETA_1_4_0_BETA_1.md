# Cinema TMS Admin 1.4.0 Beta 1

## 하드웨어 키 기존 라이선스 자동 조회

- TMS의 `.tmshw` 파일을 불러오면 하드웨어 키와 일치하는 최신 라이선스 발급 이력을 관리자 DB에서 자동으로 조회합니다.
- 고객명, 영화관명, 허용 상영관 수를 이전 정보로 채우고 기존 사용 기간·상태·담당자를 하드웨어 키 영역에 표시합니다.
- 활성 라이선스가 있으면 새 라이선스를 기존 라이선스의 갱신 이력으로 연결합니다.
- 폐기된 라이선스는 참고 정보만 불러오며 자동 갱신 대상으로 연결하지 않습니다.
- 장비 변경 요청은 이전 하드웨어 키의 활성 라이선스를 찾아 기존과 동일하게 갱신 관계를 유지합니다.

기존 형식을 변경하지 않는 신규 관리 기능이므로 `MINOR`로 판단해 `1.4.0b1`로 올렸습니다.
