# Cinema TMS Admin 1.0.0 Beta 1

## 변경 사항

- 라이선스 관리자 관련 소스·실행기·빌더·테스트·배포물을 `Cinema_Tms_Admin` 독립 프로젝트로 분리했습니다.
- 관리자 데이터 기본 위치를 프로젝트의 `data\licenses.db`로 변경했습니다.
- 클라이언트 TMS와 공유하는 공개 라이선스 계약을 독립 모듈로 분리했습니다.
- 관리자 배포 ZIP에는 실제 관리자 DB와 개인키를 포함하지 않습니다.

## 버전 판단

라이선스 관리자를 독립 프로젝트로 분리하여 별도 버전 체계를 시작했으므로 `1.0.0 Beta 1`로 분류합니다.
